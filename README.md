# Dinosaur Runner 2D

## Варіант

**Варіант №8 — 2D Runner**

Гра створена в **Unity 6.3**.

## Опис гри

**Dinosaur Runner 2D** — проста двовимірна side-view runner-гра. Динозавр автоматично рухається вправо. Гравець повинен перестрибувати кактуси, збирати монети та дістатися до фінішного прапорця.

## Керування

- `Space` — стрибок.
- Кнопка `Restart` — перезапуск рівня після перемоги або Game Over.
- Горизонтальний рух відбувається автоматично.

## Що реалізовано

- Горизонтальний рівень із чітким початком і фінішем.
- Автоматичний рух динозавра вправо.
- Стрибок після натискання `Space`.
- Ground check, який не дозволяє виконувати подвійний стрибок.
- Камера, яка рухається за динозавром по осі X.
- Не менше 20 перешкод.
- Три різні патерни перешкод:
  - один кактус;
  - два кактуси;
  - три кактуси.
- Не менше 10 collectibles.
- Монети, кожна з яких додає 1 бал.
- Відображення поточного score під час проходження рівня.
- Зіткнення з кактусом викликає Game Over.
- Після Game Over відображається фінальний score.
- Кнопка Restart для повторного проходження рівня.
- Фінішний trigger.
- Після досягнення фінішу відображається You Won і фінальний score.
- Після перемоги або Game Over динозавр припиняє рух.
- Анімація бігу динозавра.
- Рівень тривалістю приблизно 30–60 секунд.

## Що не встигли реалізувати

- Анімацію смерті динозавра.
- Звукові ефекти та фонову музику.
- Повноцінний parallax-ефект для хмар і фонових об’єктів.
- Головне меню та меню налаштувань.
- Збереження найкращого результату між запусками гри.

Ці функції не були обов’язковими для виконання лабораторної роботи.

## Що додано поза основним завданням

- Окремі UI-панелі для Game Over і перемоги.
- Відображення фінального score.
- Графічна кнопка Restart.
- Анімація бігу динозавра.
- Pixel-art оформлення рівня.

## Основні компоненти

- `DinosaurRunner2D` — автоматичний горизонтальний рух.
- `DinosaurJump2D` — стрибок і перевірка землі.
- `CameraFollow2D` — слідування камери за гравцем по осі X.
- `Collectible2D` — збір монет.
- `Obstacle2D` — обробка зіткнення з перешкодами.
- `FinishTrigger2D` — завершення рівня.
- `GameManager2D` — score, Game Over, перемога та перезапуск рівня.
